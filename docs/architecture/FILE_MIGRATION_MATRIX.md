## Summary of Physical Folder Alignment

1. **Retired `framework/` at Root**: All 39 files formerly under `framework/` have been migrated to `src/simulation/`, `materials/`, `scenarios/`, `src/output/`, and `src/numerics/`. The `framework/` directory has been removed.
2. **Centralized `materials/`**: All constitutive models, state definitions, evolution laws, diagnostics, adapters, and native C++ transaction bindings live under `materials/`, with optional subsystem `materials/cl-mpm-materials.asd`. The legacy `src/models/` directory and root `src/{constitutive,particle,cpp,fastmaths}.lisp` shims have been removed.
3. **Domain-Grouped `src/` Engine**: All engine modules are organized into the 15 Section 2 subdirectories (`core/`, `geometry/`, `discretization/`, `transfer/`, `boundaries/`, `loading/`, `solvers/`, `formulations/`, `stabilization/`, `damage/`, `numerics/`, `parallel/`, `simulation/`, `measurements/`, `output/`). Legacy `src/bc/`, `src/dynamic-relaxation/`, `src/mpi/`, `src/ssa/`, and `src/solvers/octree/` folders have been relocated into their Section 2 domain folders.
4. **Scenario-Grouped `cases/`**: Case recipes are organized under `cases/triaxial/`, `cases/cliff/`, `cases/benchmarks/`, and `cases/direct-shear/` (with automatic alias resolution in `scripts/run-case.lisp` for historical flat case paths).
