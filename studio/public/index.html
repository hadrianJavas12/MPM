Visualisasi Partikel 3D & Tensor Tegangan

Rangkaian file .vtk disimpan di folder output\studio\vtk\. Anda dapat membukanya secara interaktif di ParaView untuk melihat pemodelan 3D, memotong bidang slice, atau menganalisis medan strain tensor.

  1. Buka ParaView lalu pilih File → Open.
  2. Buka folder output\studio\vtk\ dan pilih sequence sim_..vtk.
  3. Klik tombol Apply, lalu ubah pewarnaan menjadi damage atau velocity.
