# CL-MPM

Material point method code in Common Lisp (SBCL only), by Sam Sutcliffe. Upstream: `samjvsutcliffe/cl-mpm` (`origin/main` = `d8e6554`).
Explicit dynamics with mass scaling, GIMP shape functions, non-local continuum damage, plastic models (von Mises, Mohr–Coulomb, Drucker–Prager), VTK output and a gnuplot live plotter.
