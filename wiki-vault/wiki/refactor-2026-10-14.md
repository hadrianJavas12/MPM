# Refactor of the Gemini Windows port (2026-10-14)

**Goal:** make the port clean, relocatable and documented without breaking Linux.

**Decisions**
- Feature-gate everything (`:win32` → `:cl-mpm-no-mpi`) instead of editing `src/` logic; `src/utils.lisp` restored to upstream.
- Replace root-level Gemini scripts with `windows/`, `studio/`, `scripts/`; binaries moved under git-ignored `toolchain/`; ~196 MB of duplicate DLLs and generated clutter removed.
- Fix real bugs found on the way: missing `%DSYEV` ([[magicl-patches]]), invalid chalk initargs, single-float JSON parsing, gnuplot alias failure ([[windows-port]]).
- Add `docs/` and a smoke test (`scripts/smoke-test.lisp`).

**Safety:** branch `backup/gemini-windows-port`.

**Results:** smoke test passes; `cl-mpm/examples/chalk` loads and runs; Studio runner and server API verified (damage on, 3 frames, PNG+VTK+video).

See [[cl-mpm]], [[cl-mpm-studio]], [[serial-mpi-standin]].
